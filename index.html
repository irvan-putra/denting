ask an assistant (manual)

No AI is built into denting. This copies a short brief of the piece and the exact edit vocabulary; you paste it to an assistant you already use, then paste its plan back. denting checks a plan and shows what it would do before touching the music. Plans can only use the same edits as typed commands; composing a new piece from a description is not possible this way.

score

A reading picture of the written notes, snapped to a sixteenth-note grid. Loudness, fine timing, tempo/meter changes and independent overlapping voices are not shown. It is drawn in two-bar groups, each restating clef and tempo, and a group never splits across a printed page; the last page can be short. Ties between two-bar groups are omitted; the .mid file stays the source of truth.
